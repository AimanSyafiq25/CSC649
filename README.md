# CSC649 Setup Experiment

## Description

This program accepts a sentence from the user and displays the number of words and characters in the sentence.

The program also handles empty input by displaying a suitable message.

## How to Run

1. Open the project in PyCharm.
2. Make sure the Python interpreter is the project's `.venv` environment.
3. Open `main.py`.
4. Run the program.
5. Enter a sentence when prompted.

## Test Results

### Test 1: Normal sentence

Input:

I love Python

Output:

Word count: 3
Character count (including spaces): 13

### Test 2: Empty input

Input:

No input was entered.

Output:

You did not enter a sentence.

### Test 3: Extra spaces

Input:

I   love    Python

Output:

Word count: 3

The character count includes the extra spaces.

## Limitation

The program only works with text entered through the console and does not save the user's input or results after the program ends."# CSC649"
